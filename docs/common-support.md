# 公共支撑与独立维护

XSSC 使用产品中立的 XCSc 文件、SQLite、锁和身份原语，不依赖 XCSS 或整个 Server，公共库没有常驻服务。XSSI 的独立 setup 根据产品生成并由发行清单绑定的配置 Schema、默认值、DDL、凭据策略、资源声明、语义规则及正负样例实现操作，不复用 Server 运行实现或传递业务依赖。

运行 Server 不识别工具标记、不取得工具锁、不含首装和离线维护命令。脚本、XSSC 和独立辅助程序协调同一安装工具锁；写入控制由管理员工具与系统管理器负责。

发行物料生成器及对应发布测试使用 `build-tools-source.json` 指定的官方 XSSI 完整提交。CI 独立检出到 `.release-build-tools`；本地也可以通过 `XSSI_BUILD_TOOLS_DIR` 指定该提交的清洁检出。测试核验提交和目录状态，不依赖相邻仓库，也不会从搜索路径选取其他实现。
