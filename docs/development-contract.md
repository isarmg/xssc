# 实现约束

XSSI 是独立的安装维护仓库，包含脚本与离线辅助程序；XSSC 是独立升级核心。工具仅复用产品中立公共原语，依据发行绑定的生成契约实施，不链接整个 Server、XCSS 或业务传递依赖；产品运行时不能反向依赖、探测或调用工具。

server 只有 --root 运行入口；首装、离线校验、密码重置和媒体配置重建属于独立 setup。安装脚本负责系统账号、目录权限、程序安装和 systemd。XSSI 升级先下载、校验 SHA256 并预检系统单元；XSSC 负责持久启动控制、停止 writer、备份、当前结构只读校验、程序切换、启动和真实就绪。

所有项目仅使用当前唯一合同，无别名、旧 JSON、旧目录、旧 CLI 或旧数据格式兼容。当前结构不匹配必须在程序切换前拒绝；不提供历史结构迁移或转换入口。

快照、验证、程序切换和恢复保持资源组一致。服务可能已经接收写入后，不得默认恢复旧数据。进程执行有界、清理环境、封存文件描述符、root 辅助程序接收显式服务 UID/GID 作为资源所有者参数，权限验收独立探测真实服务身份，错误输出不泄露密码、密钥或子进程秘密。

固定 ROOT 不代表整个 ROOT 是升级载荷。程序路径以完整SHA256文件清单为界，配置与业务路径以独立辅助程序报告为界，维护记录不混入业务快照。[合同](offline-upgrades.md)
