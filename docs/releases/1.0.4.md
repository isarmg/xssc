# xssc 1.0.4

升级事务改为唯一的 `fixed-root-payload-v1` 合同。XSSI 脚本先下载并核对 SHA256 包，委托 XSSC 持久记录系统管理器启动控制、停止全部已声明 writer、备份、只读检查当前结构、替换程序、受控启动并确认真实程序摘要和业务就绪。

源安装和目标包都必须通过完整 SHA256 清单验证。持久资源范围由源辅助程序的配置报告授权；升级只替换明确列出的程序文件，不覆盖整个安装目录。没有旧 CLI、目录选择器、管理员 JSON 或旧包结构的兼容代码。

预检查失败会清理本次创建且目录身份仍匹配的工作目录中的 target-payload 暂存区。中断记录与备份继续保留；服务已经可能写入业务数据时，恢复需要显式的数据丢失授权。XCZS 明确声明的共享业务目录可以保留多个文件所有者、组写权限、修改时间和 Linux POSIX ACL，包括嵌套 default ACL 及原本无 ACL 的条目，私有数据库、配置和日志仍使用独立权限检查。

验证包含 SHA256 与完整文件覆盖、权限和平台核对、状态备份恢复、只读检查副作用拒绝、独立当前结构检查、服务真实就绪、共享所有权、ACL 和修改时间保留、运行锁 inode 保留、恢复中断重试，以及预检查失败后的再次升级。完成事务、备份和回收记录按明确保留策略回收，默认只输出计划；未知、未完成或仍承担恢复义务的内容保留。发布归档为 `xssc-1.0.4-linux-x86_64.tar.zst`，正式资产包含完整文件清单与 SHA256 摘要。
