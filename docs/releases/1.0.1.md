# xssc 1.0.1

修复已停止的 systemd 单位被卸载后，升级与恢复工具无法读取实际启动控制条件的问题。工具通过 systemd 的 `LoadUnit` 加载单位元数据，再严格检查实际加载的状态、控制文件和完整启动条件；这一步不会启动或启用服务。

XSSC 为六个 Server 提供固定 ROOT 的升级与恢复核心，由独立 XSSI 升级脚本调用。工具软件版本为 1.0.1，自有包清单、升级计划、事务日志、启动控制记录和材料回收记录仍采用 v1。当前数据结构不一致直接拒绝，不提供旧版本兼容、数据转换或迁移入口。

Linux x86_64 GNU 发行包从清洁源码和实际目标构建，绑定运行依赖图、许可证原文、最终文件和原生依赖库存，并使用完整 SHA256 清单。发行不使用自定义签名或发行私钥。

实际发行结果以正式工作流和资产核验为准。操作、约束和恢复流程见[项目说明](../../README.md)及[离线升级文档](../offline-upgrades.md)。
