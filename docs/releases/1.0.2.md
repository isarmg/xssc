# xssc 1.0.2

## 更新

- 公共客户端支撑升级到正式 `xcsc 1.0.3`，固定完整源码修订 `5641a33e991209eecdbbc91cffaa3be545875757`，继续启用 `offline-maintenance` 功能。
- 修复普通用户恢复包含 `0500` 或 `0555` 只读子目录的归档时，过早恢复目录权限导致子项写入失败的问题。恢复期间新建目录暂用 `0700`，子项完成后从叶到根恢复归档中的模式。
- 回归覆盖只读嵌套目录的内容、模式、属主、重复恢复和维护门 inode 保留；原子文件替换和路径处理机制不变。

## 下载与部署

发行目标为 Linux x86_64 GNU 归档 `xssc-1.0.2-linux-x86_64.tar.zst` 和对应 `.sha256`。归档包含工具、签名、构建清单和离线文档。此说明不代表候选源码已经打标签、签名或发布。

工具安装和运行步骤见[平台部署指南](../platform-setup.md)。
