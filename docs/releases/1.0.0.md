# xssc 1.0.0

XSSC 为六个 Server 提供固定 ROOT 的升级与恢复核心，由独立 XSSI 升级脚本调用。它没有常驻服务，不被 Server 运行时调用。工具软件版本为 1.0.0，自有包清单、升级计划、事务日志、启动控制记录和材料回收记录均采用当前 v1 格式。

升级脚本下载精确版本并核验完整 SHA256 清单，在停服前检查安装身份与实际加载的 systemd 单元。随后限制并停止全部 writer，取得真实退出证明和运行锁，保存完整快照，再调用源、目标独立辅助程序进行只读数据检查。当前结构不一致直接拒绝，不提供旧版本兼容、数据转换或迁移入口。

程序切换仅处理发行清单声明的资源，启动后核验实际运行文件摘要与 `/readyz`。持久快照包含字节、所有者、权限、受控 POSIX ACL 和纳秒修改时间。恢复默认保留服务可能启动后产生的新写入；材料回收只删除持久记录授权且已完成的对象，未知 inode、引用和未完成操作均保留。

Linux x86_64 GNU 发行包从清洁源码和实际目标构建，绑定运行依赖图、许可证原文、最终文件和原生依赖库存，并使用完整 SHA256 清单。发行不使用自定义签名或发行私钥。第三方依赖及标准格式保留实际版本。

实际发行结果以正式工作流和资产核验为准。操作、约束和恢复流程见[项目说明](../../README.md)及[离线升级文档](../offline-upgrades.md)。
