# xssc 1.0.3

## 更新

- 修复升级后业务数据正常增长超过旧 `max_backup_bytes` 预算时，已停服并明确授权丢弃后续写入的恢复仍在 `recovery-restoring` 阶段失败的问题。目录资源和独立文件资源都支持按完整旧快照恢复。
- 备份预算继续限制原程序与状态快照，不再误用于恢复时即将覆盖的当前数据；完整备份验证、停服要求、数据损失授权及原有路径、属主、类型、条目数和深度检查保持不变。
- 增加目录增长、独立文件增长和原始备份超预算仍拒绝的回归；同步当前工具安装文档的版本与下载示例。
- 恢复修复不改变依赖；合并后的源码保留本地基准的 `xcsc 1.0.4`、完整源码修订 `9cff5bc1425072533fcb8984ee4820b1f6ab6a5c`，继续启用 `offline-maintenance` 功能。此公共支撑修订为本地已验证、尚未推送或发布的候选输入。

## 下载与部署

发行目标为 Linux x86_64 GNU 归档 `xssc-1.0.3-linux-x86_64.tar.zst` 和对应 `.sha256`。归档包含工具、签名、构建清单和离线文档。此说明不代表候选源码已经打标签、签名或发布。

工具安装和运行步骤见[平台部署指南](../platform-setup.md)。恢复默认保护运行权交接后的新增写入，只有明确接受丢弃这些写入时才使用 `--allow-data-loss`；详见[失败恢复与数据损失授权](../offline-upgrades.md#失败恢复与数据损失授权)。

## 验证范围

回归使用临时目录中的真实文件、签名、快照与事务记录，服务生命周期和产品校验使用既有测试替身。验证覆盖无授权仍拒绝、授权后恢复原数据和程序，以及原始备份预算继续生效；不替代真实 systemd、实际产品发行制品、root 身份分支或其他平台验收。
